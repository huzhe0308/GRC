# GB 44497-2024 智能网联汽车自动驾驶数据记录系统

## Overview

GB 44497-2024 is a mandatory Chinese national standard titled "Intelligent and connected vehicle — Data storage system for automated driving" (智能网联汽车 自动驾驶数据记录系统). Published on 23 August 2024 with effective date 1 January 2026, it specifies technical requirements, test methods, and type approval criteria for automated driving data recording systems (ADS data loggers). The standard defines two system types (Type I and Type II) with different data recording requirements, covering collision events, collision-risk events, continuous recording, data elements, storage, reading, information security, crash performance, and environmental evaluation. It is a key component of the ICV (Intelligent Connected Vehicle) regulatory framework alongside GB/T 44721 (ADS general requirements) and GB 39732-2020 (EDR).

## Scope and Requirements

- Defines automated driving data recording system (自动驾驶数据记录系统) with two types:
  - **Type I system**: M₁/N₁ vehicles — records time-segment events (collision, collision-risk) and timestamp events (ADS activation/deactivation, intervention request, MRC, severe failures)
  - **Type II system**: M₂/M₃/N₂/N₃ vehicles — continuous real-time recording plus timestamp events
- **Collision event trigger**: per GB 39732-2020 criteria; record start = 15s before event or ADS activation (whichever later); record end = 5s after event, ADS deactivation, or event end (whichever earliest)
- **Collision-risk event trigger**: when ADS requests longitudinal deceleration >5 m/s²
- **Timestamp events**: ADS activation, deactivation, intervention request, MRC execution, ADS severe failure, vehicle severe failure, user-operated ADS deactivation device
- **Data elements classified**: A-level (always required) and B-level (required when function is called by AD)
- **Data storage**: locked status for collision events (data cannot be overwritten)
- **Data reading**: standardized export file format (Annex B)
- **Information security**: cybersecurity requirements for the data recording system
- **Crash performance**: must survive crash per GB 11551 (frontal), GB 20071 (side), GB/T 20913 (offset frontal)
- **Environmental evaluation**: per GB/T 28046 series (electrical/electronic equipment environmental conditions)
- **Type approval**: direct equivalence conditions and test-verified equivalence conditions

## Technical Details

- Collision event record window: T₀−15s to T₀+5s (minimum 20s total)
- Collision-risk trigger threshold: ADS-requested deceleration >5 m/s²
- Data element classification: A-level (mandatory) vs. B-level (conditional on AD function call)
- Field of viewing angle (视场角) defined for camera-based recording systems
- Lock status: collision event data cannot be overwritten
