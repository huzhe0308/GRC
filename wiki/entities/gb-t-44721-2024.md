# GB/T 44721-2024 智能网联汽车自动驾驶系统通用技术要求

## Overview

GB/T 44721-2024 specifies general technical requirements for automated driving systems (ADS) in intelligent connected vehicles (智能网联汽车 自动驾驶系统通用技术要求). A WD draft (GB XXXXX—XXXX, 征求意见稿) is being developed to replace it, renaming the standard to "自动驾驶系统安全要求" (Safety requirements for automated driving system). The published 2024 standard covers overall requirements, dynamic driving task (DDT) execution, fallback requirements, and human-machine interaction for ADS. The draft revision expands scope to L3 and L4 ADS explicitly, adds safeguard requirements, safety file inspection, same-type determination, and implementation provisions, reflecting the maturation of China's autonomous driving regulatory framework.

## Scope and Requirements

### GB/T 44721-2024 (Published)

- **Scope**: Specifies overall requirements, DDT execution requirements, DDT fallback requirements, and HMI requirements for ADS; applies to M and N category vehicles
- **Normative References**: GB/T 34590.1, GB/T 34590.3-2022, GB/T 40429-2021 (automation levels), GB/T 41798 (closed-field test), GB/T 43267-2023 (SOTIF), GB/T 44298-2024, GB/T 44373-2024, GB/T 44719 (road test)
- **Key Terms**: Autonomous driving function, ADS (L3+), inactive state, ready state, active state, activation, deactivation, ODD, ADS severe failure, vehicle severe failure, planned takeover event
- **Overall Requirements** (Ch.4):
  - 4.1: ADS must have clearly defined ODC (operational design condition)
  - 4.2: ADS must operate only within its ODD
- **Introduction**: Part of multi-pillar verification approach (audit, simulation, closed-field, road test); supports validation through coordination with test standards

### GB XXXXX—XXXX (Draft Revision)

- **Scope**: Specifies technical requirements, safeguard requirements, same-type determination for L3/L4 ADS (excluding parking systems); describes safeguard inspection, safety file inspection, and confirmatory test methods
- **Normative References**: GB 21670 (braking), GB/T 41798 (closed-field test), GB 44497 (data recording), GB/T 44719 (road test), GB/T 45312 (ODC), GB/T 47025 (simulation test)
- **Key Changes from 2024 version**:
  - Renamed to emphasize "safety requirements" (安全要求)
  - Changed scope to L3/L4 only (excluding parking)
  - Added abbreviations chapter (Ch.4)
  - Changed DDT requirements (Ch.5.1), HMI requirements (Ch.5.2), user notification (Ch.5.3)
  - Added safeguard requirements (Ch.6) and inspection (Ch.7)
  - Added safety file inspection (Ch.8)
  - Changed confirmatory tests (Ch.9)
  - Added same-type determination (Ch.10) and standard implementation (Ch.11)
  - Added Appendix A (takeover capability monitoring), B (L3 on high-speed roads), C (L4 additional requirements), D (safety file)
