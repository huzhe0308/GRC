# GB/T 47351-2026 智能网联汽车车控操作系统技术要求及试验方法

## Overview

GB/T 47351-2026 specifies technical requirements and test methods for vehicle-control operating systems in intelligent and connected vehicles (智能网联汽车 车控操作系统技术要求及试验方法). The standard distinguishes between Type I (intelligent driving OS) and Type II (safety vehicle-control OS) systems, covering general requirements, technical specifications, information security, functional safety, and corresponding test methods. It provides the foundational software platform requirements for safe and reliable automated driving, defining the architecture and performance criteria for the operating systems that will underpin China's next-generation intelligent vehicle computing platforms.

## Scope and Requirements

- **Scope**: Specifies general requirements, universal technical requirements, information security requirements, functional safety requirements, and test methods for vehicle-control operating systems.
- **Applicability**: Applies to M and N category vehicles equipped with vehicle-control OS; other vehicle types may refer to this standard.
- **System Types** (§4.1.1):
  - **Type I (Intelligent Driving OS)**: Supports driving automation functions; designed for AI workloads and perception/decision-making tasks
  - **Type II (Safety Vehicle-Control OS)**: Supports safe and reliable vehicle operation; designed for real-time control and safety-critical tasks
- **Architecture**: Vehicle-control OS runs on on-board intelligent computing base platform hardware and ECU hardware, comprising:
  - **System Software**: Kernel, virtualization layer, middleware
  - **Functional Software**: Data abstraction, common framework, intelligent driving models, API layer
- **Key Concepts**: Defines hardware virtualization, dynamic orchestration, security audit, and data abstraction as core capabilities.
- **Functional Safety** (§4.3): Requires compliance with GB/T 34590.6 (software-level product development per ISO 26262 Part 6), with separate requirements for Type I and Type II systems.
- **Information Security** (§4.4): Separate requirements for Type I and Type II, referencing GB 44495-2024 and GB 44496-2024.
- **Normative References**: GB/T 17548-2008 (POSIX compliance), GB/T 34590.6 (functional safety software), GB/T 40429-2021 (automation levels), GB/T 44373-2024 (ICV terminology), GB/T 46194-2025 (cybersecurity engineering), GM/T 0005-2021 (randomness testing).
