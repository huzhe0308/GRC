# GB 18285-2018 汽油车污染物排放限值及测量方法

## Overview

GB 18285-2018 is a mandatory Chinese national standard specifying emission limits and measurement methods for gasoline vehicles using the dual-idle method (双怠速法) and simplified driving cycle method (简易工况法). Jointly issued by the Ministry of Ecology and Environment (MEE) and the State Administration for Market Regulation (SAMR), it replaces GB 18285-2005 and HJ/T 240-2005, implementing stricter in-use vehicle emission controls aligned with the China 6 framework. The standard covers new vehicle production line inspection (新生产汽车下线检验), registration inspection (注册登记检验), and in-use vehicle inspection (在用汽车检验), adding OBD checks, visual inspection, and fuel evaporation control system inspection that were absent from the 2005 version.

## Scope and Requirements

- Specifies emission limits and measurement methods for gasoline vehicles using four test methods: dual-idle (双怠速法, Appendix A), steady-state cycle (稳态工况法, Appendix B), transient cycle (瞬态工况法, Appendix C), and simplified transient cycle (简易瞬态工况法, Appendix D)
- Covers visual inspection (外观检验), OBD system checks (OBD检查, Appendix F), and fuel evaporation emission control system inspection (燃油蒸发排放控制系统检测, Appendix E)
- Applicable to: new production vehicle line inspection, registration inspection, in-use vehicle inspection, and other spark-ignition engine vehicles
- Defines vehicle classifications: M₁ (≤9 seats), M₂ (>9 seats, ≤5000kg), N₁ (≤3500kg goods), heavy-duty (>3500kg)
- Key test methods defined in appendices: Appendix A (dual-idle), Appendix B (steady-state), Appendix C (transient), Appendix D (simplified transient), Appendix E (evaporation), Appendix F (OBD), Appendix H (real-time data reporting)
- Exhaust pollutants measured: CO, HC, NOₓ (nitrogen oxides), with carbon-hydrogen ratio assumptions per fuel type
- Reference mass (基准质量) defined as vehicle kerb mass plus 100 kg; equivalent inertia used for chassis dynamometer simulation
- Key revisions vs. 2005: added visual inspection, OBD checks, fuel evaporation detection, inspection process/flow requirements, compensation value recording, and detection software requirements
- Dual-idle method: high-idle (2500±200 rpm) and low-idle measurements; CO and HC limits vary by vehicle category and emission stage
- OBD check procedures: verify MIL (malfunction indicator lamp) status, read/clear DTCs, confirm communication per ISO 15031-5 / SAE J1979 protocols

## Technical Details

- Base reference mass: kerb mass + 100 kg (Section 3.11)
- Carbon-hydrogen ratio assumptions used for FID analyzer calculations, varying by fuel type (gasoline, LPG, CNG, etc.)
- Dual-idle test: high-idle at 2500±200 rpm, low-idle at manufacturer-specified idle speed
- Steady-state cycle (ASM): loads and speeds set per vehicle reference mass categories
- Transient cycle (VMAS): simulated driving pattern on chassis dynamometer with real-time dilution analysis
