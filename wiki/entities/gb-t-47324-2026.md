# GB/T 47324-2026 车联网平台网络安全防护要求

## Overview

GB/T 47324-2026 specifies cybersecurity protection requirements for Internet of Vehicles (IoV) platforms (车联网平台网络安全防护要求). The standard establishes a five-level security protection classification system (第一级至第五级) covering physical environment security, security management, and security technology requirements at each level. Drafted by the China Academy of Information and Communications Technology (中国信息通信研究院) with industry participation from NIO, Xiaomi Auto, Chang'an, and others, it provides the framework for protecting connected vehicle platforms against cyber threats, covering infrastructure security, application service security, and protection of sensitive personal information including vehicle location tracks and biometric features.

## Scope and Requirements

- **Scope** (Ch.1): Specifies cybersecurity protection requirements for IoV platforms, including physical environment security, security management, and security technology at five protection levels
- **Applicability**: Applies to intelligent connected vehicle manufacturers, IoV platform operators, and related entities conducting cybersecurity graded protection work
- **Five-Level Classification**: Establishes five security protection levels based on importance of the IoV system and potential impact of security breaches on national security, social order, economic operations, public benefit, and user interests
- **Security Protection Content** (Ch.5): Three main categories:
  - **Physical Environment Security**: Physical location selection, access control, anti-theft/anti-sabotage, lightning protection, fire prevention, water/damp protection, anti-static, temperature/humidity control, dust prevention, power supply, electromagnetic protection
  - **Security Management**: Security management systems, security management organizations and personnel, platform security construction management, platform security operations management
  - **Security Technology**: Infrastructure security (computing environment, communication network, area boundary, security management center, virtualization, container, common middleware, common interface) and application service security (general requirements, upgrade services, remote control, remote monitoring, remote diagnosis, charging management/monitoring)
- **Level Requirements** (Ch.6–10): Each level (1–5) specifies increasingly stringent requirements for physical environment, management, and technology
  - Level 1: Basic protection; physical per GB/T 22239 Level 2 requirements
  - Level 2–5: Progressively enhanced requirements with additional controls
- **Key Definitions**:
  - IoV cybersecurity protection: measures to prevent attacks, intrusions, interference, damage, and unauthorized use ensuring stable operation and data integrity, confidentiality, availability
  - Sensitive personal information: includes vehicle location tracks, audio, video, images, biometric features
  - Common middleware: microservice, message, and web service middleware

## Technical Details

- Physical environment Level 1 requirements reference GB/T 22239 Level 2 for basic protection
- Abbreviations: CPU, DTC (diagnostic trouble code), FTP, HTTP, HTTPS, IP, OTA, POP3, SMTP, SSL, TLS, VIN
- Technology areas include: computing environment, communication network, area boundary, security management center, virtualization, container, common middleware, common interface security
- Application service areas include: upgrade services (OTA), remote control, remote monitoring, remote diagnosis, charging management/monitoring
