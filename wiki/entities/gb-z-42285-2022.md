# GB/Z 42285-2022 道路车辆电子电气系统ASIL等级确定方法指南

## Overview

GB/Z 42285-2022 is a Chinese national standardized guiding technical document (国家标准化指导性技术文件) that provides guidelines for ASIL (Automotive Safety Integrity Level) determination for electrical/electronic (E/E) systems in road vehicles. It complements the GB/T 34590 (ISO 26262) series by offering practical guidance on hazard identification using HAZOP (Hazard and Operability Analysis), risk assessment, and ASIL classification. The document includes worked examples for steering, drivetrain, suspension, and braking functions, providing concrete illustrations of how to apply the HARA methodology to real automotive systems.

## Scope and Requirements

- **Scope** (Ch.1): Provides guidelines for ASIL determination methodology applicable to safety-related E/E systems installed in production road vehicles (excluding mopeds); ASIL determination is required by GB/T 34590.3-2022
- **Hazard Identification** (4.1): Describes Hazard Analysis and Risk Assessment (HARA) as the core process — identifies potential hazards, forms hazard events with operational scenarios, assesses risk to determine ASIL and safety goals
- **HAZOP Method**: Recommends Hazard and Operability Analysis (HAZOP) as hazard identification technique, using guide words applied to each item function:
  - a) Function loss (功能丧失) — function not provided when needed
  - b) Wrong function (错误功能) — more/less than expected, or wrong direction
  - c) Unintended function (非预期功能) — function provided when not needed
  - d) Output stuck (输出卡滞) — function cannot update as expected
- **Risk Assessment** (4.2): Covers severity, exposure, and controllability assessment per GB/T 34590
- **Safety Goals** (4.3): Defines relationship between safety goals and safe states
- **Worked Examples** (Appendices):
  - Appendix A (Informative): Vehicle-level motion behaviors along different axes
  - Appendix B (Informative): Severity grading guidelines
  - Appendix C: Steering function HARA — item definition, HAZOP analysis, full risk assessment
  - Appendix D: Drivetrain and transmission — hazard identification, HARA, detailed example
  - Appendix E: Suspension control — hazard analysis and risk assessment, additional considerations
  - Appendix F: Braking and parking brake — HAZOP analysis and full HARA

## Technical Details

- HAZOP guide words applied to steering and braking functions: function loss, wrong function (more/less/reversed direction), unintended function, output stuck at fixed value
- Risk assessment follows GB/T 34590: severity (S), exposure (E), controllability (C) → ASIL determination (A/B/C/D or QM)
- Vehicle motion behaviors classified along longitudinal, lateral, and vertical axes (Appendix A)
- HARA must consider maintenance personnel, but not pre-existing faults during repair/maintenance
- Note: Not all HAZOP guide words apply to all analyses — must be tailored to analysis scope
