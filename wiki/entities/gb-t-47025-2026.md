# GB/T 47025-2026 智能网联汽车 自动驾驶功能仿真试验方法及要求

## Overview

GB/T 47025-2026 specifies simulation test methods and requirements for automated driving functions of intelligent and connected vehicles. Published and effective on 28 January 2026, the standard defines how to evaluate automated driving systems (ADS) using simulation test toolchains, including requirements for test credibility, scenario generation, and pass/fail criteria. It defines key concepts including simulation test (仿真试验), simulation test toolchain (仿真试验工具链), simulation test tool (仿真试验工具), and simulation model (仿真模型). The standard covers a comprehensive range of driving scenarios from traffic signal recognition to emergency avoidance, with 10 appendices providing detailed test specifications.

## Scope and Requirements

- **Scope**: Defines simulation test methods and requirements for automated driving functions of ICVs
- **Applicability**: Applies to M and N category vehicles with automated driving functions, or to automated driving systems themselves
- **Test Objects**: Test objects must include at minimum the automated driving system; no modifications to the ADS or simulation toolchain are permitted during testing
- **Key Definitions**:
  - **Simulation test (仿真试验)**: Testing ADS or ADS-equipped vehicles using simulation test toolchains in simulated scenarios
  - **Simulation test toolchain (仿真试验工具链)**: A combination of one or more simulation test tools and models for conducting simulation tests
  - **Simulation test tool (仿真试验工具)**: Software and/or hardware devices used for ADS simulation testing
  - **Simulation model (仿真模型)**: Models in simulation environments where input variables change over time
- **Simulation Credibility**: Must be assessed per Annex A, covering toolchain confidence levels
- **Toolchain Requirements**: Must support selected test items, run concrete test scenarios (road networks, target objects), and have capability to connect ADS models, algorithms, or hardware
- **Commercial Vehicle Testing**: Commercial vehicle test vehicles must be tested in both curb weight (整备质量) and maximum allowable total mass (最大允许总质量) states
- **Normative References**: GB/T 3730.2, GB 5768 (traffic signs), GB 14886/14887 (traffic signals), GB/T 40429 (automation levels), GB/T 41798 (closed-course test methods), GB/T 44373 (ICV terminology), GB/T 45312 (ODD), GB/T 46896 (test scenario terminology)

### Appendices
- **Annex A (normative)**: Simulation test credibility assessment (仿真试验可信度评估)
- **Annex B (informative)**: Target object dimensions (目标物尺寸)
- **Annex C (normative)**: Traffic signal recognition and response
- **Annex D (normative)**: Road traffic infrastructure and obstacle recognition and response
- **Annex E (normative)**: Pedestrian and non-motorized vehicle recognition and response
- **Annex F (normative)**: Surrounding vehicle driving state recognition and response
- **Annex G (normative)**: Automatic emergency avoidance (自动紧急避险)
- **Annex H (normative)**: Bus stop area scenarios (公交站台区域场景)
- **Annex I (normative)**: Minimum risk strategy (最小风险策略)
- **Annex J (informative)**: Test scenario parameter summary (试验场景参数汇总表)

## Technical Details

- Published and effective: 2026-01-28
- Commercial vehicles tested in both curb weight and maximum total mass states
- Target object dimensions specified in Annex B
- 7 normative scenario appendices + 1 normative credibility assessment + 2 informative appendices
- References GB/T 41798 (track testing) as complementary physical testing standard
- Simulation toolchain must support ADS model, algorithm, or hardware connections
- Credibility assessment framework defined in Annex A
