# GB/T 43267-2023 道路车辆预期功能安全 (SOTIF)

## Overview

GB/T 43267-2023 is the Chinese national standard for Safety of the Intended Functionality (SOTIF) for road vehicles, modified from ISO 21448:2022. It addresses hazards arising from functional inadequacies (not E/E failures) of intended functionality, covering the complete SOTIF lifecycle from specification and design through hazard identification, risk assessment, verification, validation, and operational phase activities. The standard includes extensive informative appendices providing guidance on SOTIF application, scenario analysis, verification/validation strategies, and specific aspects like machine learning, maps, V2X, and OTA updates. Key differences from ISO 21448:2022 include the addition of the term "优先度子集" (priority subset), modified acceptance criteria definition, changed V&V derivation method, and added Appendix E content.

## Scope and Requirements

- **Chapter 4**: SOTIF activity overview and organization — defines SOTIF principles, usage, and management/support processes; added reference to Appendix E content
- **Chapter 5**: Specification and design — functional specification, system design/architecture considerations, performance limitations and countermeasures
- **Chapter 6**: Hazard identification and assessment — hazard identification, risk assessment, residual risk acceptance criteria definition
- **Chapter 7**: Identification and evaluation of potential functional inadequacies and trigger conditions — analysis of functional inadequacies vs. trigger conditions, acceptability assessment of system response to triggers
- **Chapter 8**: Modifying functionality to address SOTIF risks — improvement measures, updating specification/design inputs
- **Chapter 9**: Defining verification and validation strategy — integration and test definition (changed V&V derivation method vs. ISO 21448)
- **Chapter 10**: Known scenario evaluation — perception verification, planning algorithm verification, execution verification, integrated system verification, residual risk assessment from known hazard scenarios
- **Chapter 11**: Unknown scenario evaluation — residual risk assessment for unknown scenarios
- **Chapter 12**: SOTIF achievement evaluation — assessment methods/criteria, SOTIF release recommendation
- **Chapter 13**: Operational phase activities — operational observation, SOTIF issue assessment and resolution process

### Key Differences from ISO 21448:2022
- Added term **"优先度子集" (priority subset)** to support SOTIF analysis, V&V, and assessment activities dealing with large numbers of scenarios and use cases
- Modified definition of **"接受准则" (acceptance criteria)** — added Note 2, Example 3, Note 3, and Note 4 for better understanding
- Changed V&V derivation method (Table 6)
- Added Appendix E content reference (Chapter 4)
- Multiple editorial changes to notes; removed source descriptions from various terms

### Appendices
- **Appendix A** (informative): SOTIF general guidance — argument structure examples, interaction between GB/T 34590 and this document, simplified SOTIF application examples, simplified specification/design examples
- **Appendix B** (informative): Scenario and system analysis guide — misuse scenario derivation, SOTIF safety analysis scenario factors, trigger condition/functional inadequacy identification examples, **STPA application for SOTIF** in ADAS and autonomous vehicles
- **Appendix C** (informative): V&V guidance
- **Appendix D** (informative): SOTIF-specific aspects — driving strategy, machine learning, maps, V2X, sensor performance, OTA
- **Appendix E** (informative): ADS risk acceptance criteria examples

## Technical Details

- GB/T 34590.1~34590.12-2022 replaces ISO 26262-1 through -12 to adapt to Chinese technical requirements
- STPA (System Theoretic Process Analysis) is specifically referenced as a SOTIF safety analysis method in Appendix B
- Appendix D covers specific SOTIF challenges including machine learning, maps, V2X communication, and OTA updates
- "Priority subset" concept helps manage the combinatorial explosion of scenarios in SOTIF analysis
- References GB/T 34590 (ISO 26262 MOD) for E/E failure-related functional safety, complementing SOTIF's focus on non-failure hazards
