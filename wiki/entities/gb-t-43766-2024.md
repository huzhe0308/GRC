# GB/T 43766-2024 智能网联汽车运行安全测试技术要求

## Overview

GB/T 43766-2024 specifies technical requirements for driving safety testing of intelligent connected vehicles (智能网联汽车运行安全测试技术要求). The standard defines requirements for test vehicles, testing organizations, test drivers/safety officers, and test operation management entities conducting road safety testing of ICVs at Level 3 (conditional automation) and above. Drafted by the Traffic Management Research Institute of the Ministry of Public Security and Baidu, it covers the full testing ecosystem from vehicle readiness to operational management, including data recording, test event storage/transmission, and safe driving ability test items.

## Scope and Requirements

- **Scope**: Applies to GB/T 40429-2021 Level 3+ ICVs conducting road safety testing, including passenger cars, buses, trucks, and special purpose vehicles
- **Key Definitions**:
  - ICV (智能网联汽车): vehicle with environment perception, intelligent decision-making, automatic control, or external information exchange capabilities
  - ADS (自动驾驶系统): hardware/software implementing L3+ autonomous driving functions
  - Safe driving ability (安全驾驶能力): includes basic driving, safe/civilized driving, and emergency avoidance driving capabilities
  - Takeover (接管): test driver or safety officer taking vehicle control from ADS
  - ODD (设计运行范围): external environmental conditions for ADS operation
- **Test Vehicle Requirements** (Ch.4):
  - Must obtain temporary license plates; should install electronic vehicle identification per GB/T 35789.1-2017
  - Must mark "自动驾驶测试" (autonomous driving test) on vehicle body
  - Must record vehicle control mode, position, speed, acceleration; communicate with test platform
  - Must record abnormal acceleration/deceleration, ADS failures, takeovers; data includes 90s before and 30s after each test event, storing ≥500 recent events
  - Must provide data port per GB 39732-2020 for querying last 2 calendar days of test event data
  - ADS mode only active on designated test roads; must monitor ODD and trigger takeover warning when approaching/exceeding ODD limits
  - Must execute minimum risk strategy when takeover not responded to
- **Test Organization Requirements** (Ch.5): Must establish accident emergency response, cybersecurity management, and data security management systems; deploy test platform for automatic data collection/analysis; submit quarterly test plans covering Appendix B test items within 18-month cycles
- **Test Driver/Safety Officer Requirements** (Ch.6): Basic requirements and test-specific requirements for personnel authorized to conduct tests and handle emergencies
- **Test Operation Management Entity** (Ch.7): Monitors and manages test activities; deploys test monitoring platform for data synchronization and event analysis
- **Appendices**: A (test event data storage and transmission), B (safe driving ability test items), C (test report example), D (traffic accident report example)

## Technical Details

- Test event data recording: 90s before + 30s after event trigger; minimum 500 recent events stored
- Test data query interface: per GB 39732-2020 Section 4.4.2; last 2 calendar days queryable
- Test plan cycle: ≤18 months, must cover all Appendix B test items
- Vehicle identification: must display "自动驾驶测试" text marking
- Road types: semi-open test roads (半开放测试道路) and public test roads (公共测试道路)
