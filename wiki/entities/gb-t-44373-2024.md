# GB/T 44373-2024 智能网联汽车术语和定义

## Overview

GB/T 44373-2024 defines terminology and definitions for intelligent connected vehicles (智能网联汽车 术语和定义). This foundational standard covers basic general terms, key technologies, system components, and functional applications related to ICVs. It serves as the terminology backbone for the ICV standard ecosystem, defining core concepts like ICV, autonomous driving, functional safety, SOTIF, cybersecurity, and various driving automation levels. The standard is referenced normatively by GB/T 44719-2024 (road test methods) and GB/T 47031-2026 (automated parking), making it a cornerstone document for the entire ICV regulatory framework.

## Scope and Requirements

- **Scope**: Defines ICV terminology covering basic general, key technology, system component, and functional application terms. Applies to M, N, and O category vehicles.
- **Basic General Terms** (Section 3):
  - ICV (智能网联汽车): Vehicle with environmental perception, intelligent decision, automatic control, or external information interaction/collaborative control capabilities
  - Driverless vehicle / ADS-DV (无人驾驶汽车/自动驾驶专用汽车): Vehicle without manual driving controls, designed for autonomous operation
  - Functional safety, SOTIF, vehicle cybersecurity, multi-pillar approach, intervention, request to intervene, takeover
  - Functional safety management system, cybersecurity management system, software update management system (SUMS)
- **Key Technologies** (Section 4): Perception, decision-making, control, communication/connected technologies.
- **System Components** (Section 5): Defines autonomous driving system (ADS), sensors, controllers, actuators, communication units.
- **Functional Applications** (Section 6): Defines various ICV functions including intelligent functions, connected functions, and their combinations; driving automation levels per GB/T 40429-2021.
