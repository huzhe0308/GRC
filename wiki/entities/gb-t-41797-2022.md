# GB/T 41797-2022 驾驶员注意力监测系统性能要求及试验方法

## Overview

GB/T 41797-2022 specifies performance requirements and test methods for driver attention monitoring systems (驾驶员注意力监测系统性能要求及试验方法). This recommended national standard defines the functional, self-check, state transition, fault indication, and EMC requirements for systems that monitor driver attention levels using image recognition technology. It also specifies driver recognition capability and detection rate/accuracy performance requirements with corresponding test methods, including the use of anthropomorphic robots (仿人机器人) as test props. The standard is applicable to M and N category vehicles equipped with image-based driver attention monitoring systems and is part of the ADAS standards ecosystem.

## Scope and Requirements

- **Scope** (Ch.1): Specifies general requirements, performance requirements, and test methods for driver attention monitoring systems based on image recognition technology; applies to M and N category vehicles
- **General Requirements** (Ch.4):
  - 4.1 Functional requirements for driver attention monitoring (DAMS) — real-time monitoring of driver state, issuing prompts when attention is分散 (distracted)
  - 4.2 Self-check requirements — system must complete self-check before entering active state; detect electrical component and sensor anomalies
  - 4.3 System state transition and information display requirements — non-active, partial active, and active states distinguished by optical signals
  - 4.4 Fault indication requirements — fault indication must include optical signal distinguishable from other indicators; visible in daylight
  - 4.5 Electromagnetic compatibility (EMC) requirements — per GB 34660
- **Performance Requirements** (Ch.5):
  - 5.1 Driver recognition capability requirements — system must recognize driver state (eyes open/closed, head position, gaze direction)
  - 5.2 Detection rate and accuracy requirements — minimum detection rate and maximum false positive rate thresholds
- **Test Methods** (Ch.6):
  - 6.1 Test conditions: environmental conditions (illumination, temperature) and test props (anthropomorphic robot per Appendix A)
  - 6.2 Driver recognition capability test: test objectives and procedures using anthropomorphic robot simulating various driver states
  - 6.3 Detection rate and accuracy test: test objectives, light sources (visible and infrared), test procedures with multiple test subjects
- **Appendix A (Normative)**: Anthropomorphic robot (仿人机器人) specifications — general requirements, characteristic requirements (head rotation, eye blink simulation, facial features), installation requirements

## Technical Details

- Technology basis: image recognition technology (基于图像识别技术)
- Key definition: "distraction" (注意力分散) includes fatigue driving, external environmental interference, or non-driving-related actions
- Test props: anthropomorphic robot with adjustable head rotation, eye blink simulation, and facial feature characteristics
- Light sources for testing: both visible spectrum and infrared illumination conditions
- Optical signal must be clearly visible to driver in normal driving position during daytime
