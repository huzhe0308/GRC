# GB/T 43253-2023 功能安全审核及评估方法

## Overview

GB/T 43253 is a multi-part standard specifying functional safety audit and assessment methods for road vehicles (道路车辆 功能安全审核及评估方法). Based on GB/T 34590 (China's ISO 26262 equivalent), it provides the processes, methods, and requirements for auditing and assessing functional safety of E/E systems throughout the safety lifecycle. The standard consists of 4 parts: general requirements, concept phase and system level, software level, and hardware level. It is essential for manufacturers and assessors to demonstrate compliance with functional safety obligations and is closely linked to the type approval process for safety-critical automotive systems.

## Scope and Requirements

### Part 1: General Requirements (通用要求)

- **Scope**: Provides general processes, implementation methods, and requirements for functional safety audit and assessment of E/E systems.
- **General Requirements** (Chapter 4): Overall audit/assessment framework and how to use the document.
- **Management Requirements** (Chapter 5): Organization culture, assessor qualifications, audit/assessment inputs, process requirements including independence criteria.
- **Technical Requirements** (Chapter 6): Covers functional safety management, concept phase and system level, software level, hardware level, production/operation/service/decommissioning, support processes, and ASIL-driven/safety-driven analysis.
- **Appendices**: A (audit/assessment report example), B (functional safety management), C (production/operation/service/decommissioning), D (support processes), E (ASIL-driven and safety-driven analysis).

### Part 2: Concept Phase and System Level (概念阶段和系统层面)

- **Scope**: Audit and assessment requirements for item definition, HARA, functional safety concept, technical safety concept, and verification/validation at concept and system levels.
- **Chapters**: Item definition (Ch.5), HARA (Ch.6), Functional safety concept (Ch.7), Technical safety concept (Ch.8), Verification and validation (Ch.9).
- **Appendices A-E**: Informative examples for each phase.

### Part 3: Software Level (软件层面)

- **Scope**: Audit and assessment requirements for software development lifecycle activities per GB/T 34590 Part 6.
- **Chapters**: Software development environment (Ch.5), Software safety requirements (Ch.6), Software architectural design (Ch.7), Software unit design and implementation (Ch.8), Software unit verification (Ch.9), Software integration and verification (Ch.10), Embedded software testing (Ch.11), Software calibration and configuration management (Ch.12), Software component qualification (Ch.13).
- **Appendices A-I**: Informative examples for each development phase.
