# GB/T 44298-2024 智能网联汽车操纵件、指示器及信号装置的标志

## Overview

GB/T 44298-2024 specifies symbols for controls, indicators, and tell-tales specific to intelligent connected vehicles (智能网联汽车 操纵件、指示器及信号装置的标志). Published on 23 August 2024, the standard defines graphic symbols and display colors for ICV-specific controls and signal devices including ADAS functions like forward collision warning, automatic emergency braking, lane departure warning, and various autonomous driving status indicators. It introduces the concept of dynamic graphic symbols composed of basic elements, where symbols can change shape, position, or add elements to indicate system/function status changes.

## Scope and Requirements

- **Scope**: Specifies symbols and display colors for ICV-specific controls, indicators, and signal devices
- **Normative References**: GB 4094, GB/T 4782, GB 5768.2, GB/T 39263 (ADAS terms), GB/T 40429 (automation levels), GB/T 44373 (ICV terms)
- **Key Definitions**:
  - **Control (操纵件)**: Driver-operated components including physical and non-physical (touch, check) controls (modified from GB 4094—2016, 3.1)
  - **Symbol (标志)**: Graphics identifying controls/indicators/signals, including static and dynamic graphic symbols; dynamic graphics use element deformation, displacement, or addition to indicate system/function status (modified from GB 4094—2016, 3.4)
  - **Initial state (初始状态)**: Initial form within a complete dynamic graphic prompt cycle
  - **Final state (最终状态)**: Final form within a complete dynamic graphic prompt cycle
  - **Basic elements (基础要素)**: Graphic element sets composing dynamic graphics
- **Requirements (Chapter 4)**: If an ICV is equipped with the controls/indicators/signals listed in Table 1, their symbols must be displayed and conform to the specified colors:
  - Forward collision warning controls/signals (red or yellow)
  - AEB controls/signals (red, yellow)
  - Lane departure warning controls/signals (yellow)
  - Various on/off, warning, fault/failure, and activation phase signal indicators

## Technical Details

- Dynamic graphic symbols can change via: element deformation (形变), displacement (位移), or addition (增加)
- Color specifications: Red and yellow are the primary signal colors for collision warning and AEB functions
- References GB/T 40429 for automation level definitions and GB/T 39263 for ADAS terminology
- The standard extends GB 4094 (general vehicle control symbols) with ICV-specific symbols
- Published and effective on the same date: 2024-08-23
