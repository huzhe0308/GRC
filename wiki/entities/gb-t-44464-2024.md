# GB/T 44464-2024 汽车数据通用要求

## Overview

GB/T 44464-2024 specifies general requirements for automotive data (汽车数据通用要求). This recommended national standard falls under the cybersecurity (CS) document collection, addressing data security requirements for vehicles including data collection, storage, transmission, and processing. It is closely associated with GB 44495-2024 (vehicle cybersecurity technical requirements), which references GB/T 44464-2024 in Clause 6 for data processing requirements. The source files consist entirely of scanned page images (28 pages for the main standard, 25+ pages for the operating procedure companion document) with no extractable machine-readable text. ^[raw/papers/CS_1_5_EN_GBT+44464-2024.md] ^[raw/papers/CS_1_5a_GBT+44464-2024_Operating_Procedure.md]
