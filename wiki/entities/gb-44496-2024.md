# GB 44496-2024 汽车软件升级通用技术要求

## Overview

GB 44496-2024 is a Chinese mandatory national standard specifying general technical requirements for vehicle software updates (汽车软件升级通用技术要求), covering both over-the-air (OTA) and offline update processes. Published on 23 August 2024, it defines requirements for the on-board software update system, update package integrity and authenticity verification, version management, rollback mechanisms, user notification and consent, and update record-keeping. The standard is referenced as a normative reference by GB 44495-2024 (vehicle cybersecurity) and forms part of China's comprehensive intelligent and connected vehicle regulatory framework alongside GB 44495, GB 44497, and GB/T 45312. The source file is image-only (binary PDF, 20 pages).

## Scope and Requirements

> **Note:** The source file is image-only. Requirements below are inferred from the standard title, its normative reference from GB 44495-2024, and the regulatory context of China's ICV framework.

- **On-Board Software Update System (车载软件升级系统):** Defines the hardware and software system for receiving, distributing, verifying, and installing upgrade packages on vehicles.
- **OTA Update (OTA升级):** Wireless transmission of upgrade packages via cellular or other wireless communication networks.
- **Offline Update (离线升级):** Non-wireless update methods including OBD interface, USB, and other physical connections.
- **Update Package Integrity:** Verification of upgrade package integrity through cryptographic checksums or digital signatures.
- **Update Package Authenticity:** Verification that upgrade packages originate from authorized sources, preventing unauthorized or malicious software installation.
- **Version Management:** Requirements for software version tracking, identification, and management across vehicle ECUs.
- **Rollback Mechanism:** Requirements for safe rollback to previous software version if update fails or causes safety issues.
- **User Notification and Consent:** Requirements for informing vehicle users of available updates, update contents, and obtaining consent for OTA updates.
- **Update Records:** Requirements for maintaining records of software updates including version, timestamp, and update status.
- **Security Requirements:** Referenced by GB 44495-2024 (Clause 7.3) for software upgrade security — ensuring update processes do not introduce cybersecurity vulnerabilities.

## Regulatory Context

GB 44496-2024 is part of China's "444XX" series of ICV mandatory standards:
- **GB 44495-2024:** Vehicle cybersecurity technical requirements (汽车整车信息安全技术要求)
- **GB 44496-2024:** Software update general technical requirements (this standard)
- **GB 44497-2024:** Autonomous driving data recording system (自动驾驶数据记录系统)
- **GB/T 44464-2024:** Automotive data security requirements (汽车数据处理安全要求)

These correspond internationally to UN R155 (cybersecurity), UN R156 (software updates), and related regulations.
