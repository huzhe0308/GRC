Vehicle type designations, Implementing acts, approval process, emission characters
Assumptions:

The following actions regarding implementing acts are announced by EU Commission:

New implementing act for Brake Particle Emissions

Integration into Main Implementing Act: Battery durability, System power measurement & PEV range at low temperatures
Note: For C1 tyres, tyre abrasion is being integrated into a new UN-R and should not therefore require a separate act, C2/C3 t.b.d.

The Brake Particle Emissions implementing act will have its own, subject specific, definition of “vehicle type”, carried over from the UN-
R on that subject.

The following scenarios are foreseen concerning the classification in an EU7 implementing act of a “new type”:

Any change that would be classified as a new type in EU6 (e.g. new engine) will trigger a new type classification in the EU7 MIA.

If a new whole vehicle type is type approved (approval to 858/2018) between 29.11.26 and 29.11.27, this will not be considered a
new type for any EU7 implementing acts

If an existing related system approval* is extended or a new related system approval* is obtained between 29.11.26 and 29.11.27
this will not  be considered a new type for individual EU7 implementing acts

For brake particle emissions approvals, the question of new type will only be asked on application for approval and therefore
there is effectively no mandatory new type date, the all vehicles date still applies.
