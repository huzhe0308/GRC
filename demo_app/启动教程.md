# G.R.C. Agent Demo 启动教程

## 1. 安装 Python 依赖

先确认电脑已经安装 Python，并且 `python` 和 `pip` 能在 PowerShell 中直接使用。

在 PowerShell 中运行：

```powershell
pip install pyyaml requests pywin32
```

## 2. 确认 Outlook 已登录

这个 Demo 现在通过 Windows COM 读取和发送邮件，所以只需要本机 Outlook 桌面客户端已经登录并可用，不需要再配置 IMAP/SMTP 授权码。

## 3. 检查配置

打开：

```text
D:\employee agent\config.yaml
```

确认下面这些项已经填好：

- `llm.api_key`：阿里云百炼 API key
- `llm.model`：`qwen3.7-max-2026-05-17`
- `mail.backend`：`outlook_com`
- `send.backend`：`outlook_com`
- `send.to`：报告接收人

## 4. 启动 Demo 网页

在 PowerShell 中运行：

```powershell
cd "C:\Users\T1UKLL7\Desktop\Workstation\employee agent"
.\start_demo.ps1
```

然后打开：

```text
http://127.0.0.1:7860
```
