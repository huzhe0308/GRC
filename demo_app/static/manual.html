3. 账号注册与登录

注册新账号

1

2
点击页面下方的 Register 切换到注册界面
3
填写：Username（小写英文）、Display Name（显示名称）、Password（至少6位）、Confirm Password

4. 安装 Bridge Agent（邮件代理）

Bridge Agent 是什么？一个运行在你本地电脑上的小程序，让云端系统通过你的电脑访问 Outlook 邮件和 AI 大模型。没有它，邮件功能和 AI 助手无法工作。

安装步骤

1
登录系统后，点击左侧导航栏 Settings
2
点击 Download Bridge Agent (exe) 下载程序
3
双击下载的 GRCBridgeAgent.exe
4
程序会弹出一个命令行窗口，提示输入 Token
5
回到网页 Settings → Show Token → 复制 Token
6
粘贴到命令行窗口，按回车

安装成功标志

✅ 命令行窗口自动关闭（程序转入后台运行）
✅ 网页顶部显示 Outlook Bridge: Connected
✅ 程序已设置为开机自启，无需重复操作

6.2 Assessment Allocation 评估分配

工作流第一步：扫描邮件/注册工单 → 解析 PSV 表格 → 分配负责人 → 发送评估邮件。

方式一：扫描邮件发现任务

1
点击 Scan Emails，系统通过 Bridge Agent 扫描 Outlook 收件箱
2
自动从邮件中提取 CEADU-XXXX 格式的 Jira 工单号
3
已发送过评估的工单显示 ✓ Processed
管理员：扫描关键词固定为 "CEADU"
其他用户：可在 Scan Emails 左侧输入框自定义关键词（逗号分隔，如 CEADU, PSV, assessment）

方式二：手动注册工单

1
在输入框输入 Jira 工单号（如 CEADU-682）
2
点击 + Ticket，系统自动从 Jira 获取工单状态和摘要
3
注册的工单显示 REGISTERED 标识，所有用户可见
已注册工单在 Jira 状态变为 Closed/Done/Resolved 后自动隐藏。点击 ✕ 可取消注册。

解析 PSV 表格 & 发送评估

1
点击任务列表中的工单，右侧显示详情
2
点击 View Parent Ticket 获取父工单信息
3
点击 Parse PSV Table 解析 PSV 附件，下方显示 Layer3 法规匹配结果
4
勾选需要的法规条目，选择收件人
5
点击 Send Assessment 通过 Outlook 发送评估邮件

6.3 Assessment Tracking 评估追踪

工作流第二步：跟踪各市场各领域的 Gap 分析进度。

领域状态说明

状态含义标识
pending等待评估灰色
evaluating评估中（Jira 有评论）蓝色
gap_analysisGap 分析完成绿色
summary_writtenSummary 已写入 Jira深绿
closedLayer3 工单已关闭已关闭
not_applicable不涉及虚线灰

操作说明

  • 点击领域 Chip：手动切换状态（pending ↔ evaluating ↔ gap_analysis）
  • 🔒 图标：手动设置的状态，自动逻辑不会覆盖（除非 Jira 有新评论）
  • Check Now：手动触发一次检测
  • Auto Monitor：勾选后每 30 分钟自动检查 Jira 评论变化
  • Write Summary Comment：所有领域完成 gap_analysis 后显示此按钮，点击后自动生成结构化摘要写入 Jira
  • Close Layer3：Summary 写入后显示此按钮，点击后自动关闭 Jira Layer3 工单
手动覆盖保护：如果你手动修改了某个领域的状态，系统不会自动覆盖（除非该 Jira 工单有新评论）。

6.5 Regulations Wiki 法规知识库

收录 30+ 篇法规文档，支持两种搜索方式：

关键词搜索（默认）

在搜索框输入关键词（如 functional safety OTA），点击 Search，系统使用 BM25 算法返回最相关的结果。

语义搜索 🔮

输入问题（如 Korea 网络安全法规要求是什么），点击 Semantic Search，系统先用关键词召回候选，再用 AI 语义打分重排，理解意图效果更好。

目录内容
raw/原始法规文档（ISO / UN-R / 国标等）
entities/法规实体卡片
concepts/概念定义
comparisons/法规对比
queries/常见问题
pvs/PSV 表格文件

8. Bridge Agent 管理指南

查看 Bridge 状态

状态栏显示含义
🟢 Outlook Bridge: Connected (用户名)Bridge 正常运行
🔴 Outlook Bridge: Not connectedBridge 未运行或已断开

Bridge 断开时怎么办

1
确认电脑已开机且未休眠
2
打开任务管理器（Ctrl+Shift+Esc），查看是否有 GRCBridgeAgent.exe 进程
3
如果没有，双击以下路径的 exe 重新启动：
C:\Users\<你的用户名>\AppData\Local\GRCBridge\GRCBridgeAgent.exe
4
如果提示 Token 过期：登录网页 → Settings → Show Token → 复制新 Token → 双击 exe

更新 Bridge Agent

下载新版本 exe 后直接双击即可。新版本会自动停止旧版本并替换，无需手动终止进程。Token 和配置自动保留。

日志位置

C:\Users\<你的用户名>\AppData\Roaming\GRCBridge\bridge.log

停止 / 禁用

操作方法
临时停止任务管理器 → 找到 GRCBridgeAgent.exe → 结束任务
禁用开机自启按 Win+R → 输入 shell:startup → 删除 GRCBridgeAgent.lnk
清除所有配置命令行运行：GRCBridgeAgent.exe --forget

9. 常见问题 FAQ

Q: 网页显示 "Outlook Bridge: Not connected" 怎么办？
Bridge Agent 未运行。请双击 C:\Users\<用户名>\AppData\Local\GRCBridge\GRCBridgeAgent.exe 重新启动。如果提示 Token 过期，去 Settings 页面获取新 Token。
Q: AI 助手提示 "LLM API key not configured" 怎么办？
你还没有配置 LLM API Key。请去 Settings 页面，在 LLM Configuration 区域输入 API Key 并保存。
Q: Scan Emails 扫描不到邮件？
可能的原因：① Bridge Agent 未连接 → 检查顶部状态栏；② Outlook 未登录或收件箱为空；③ 搜索关键词不匹配 → 非管理员用户可自定义关键词；④ 邮件已过期（默认搜索最近 30 天）。
Q: Token 多久过期一次？
Token 有效期 7 天。过期后 Bridge Agent 会自动停止，需要重新登录网页获取新 Token 并重启 Bridge Agent。
Q: 换了电脑怎么办？
在新电脑上：① 登录网页系统 → ② Settings → Download Bridge Agent (exe) 下载 → ③ 双击运行输入 Token → ④ 配置 LLM API Key。
Q: 其他用户能看到我注册的工单吗？
是的。注册的工单对所有用户可见（直到 Jira 工单状态变为 Closed/Done/Resolved 后自动隐藏），团队成员可以共享任务列表。
Q: 手动修改了评估状态，系统会自动覆盖吗？
不会。手动设置的状态显示 🔒 图标，自动逻辑不会覆盖，除非该 Jira 工单有新评论。
Q: Bridge Agent 会影响电脑性能吗？
不会。Bridge Agent 是轻量级程序，只在有请求时才工作（每 2 秒轮询一次），CPU 和内存占用极低。
Q: 多个用户能同时使用吗？
可以。每个用户有自己的账号，独立配置。但 Bridge Agent 需要每人在自己的电脑上分别安装。
Q: 忘记密码怎么办？
联系管理员重置账号。系统目前不支持自助找回密码。

如有其他问题，请联系系统管理员。
